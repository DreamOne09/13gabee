# 十三咖啡（13Gabee）Demo 網站

台中南屯秘境咖啡廳「十三咖啡」的示範官網，由 **琢奧科技** 製作（顧問簽名：Dream）。

> **本站僅供 Demo，資料來自 Google Maps／粉專等公開來源，非店家委託。**

## 本地開發

```bash
npm install
npm run dev -- --port 43123
```

瀏覽 http://127.0.0.1:43123

## 建置

```bash
npm run build
npm start
```

## 技術棧

- Next.js 16（App Router）
- TypeScript
- Tailwind CSS 4
- 照片來源：食尚玩家、婷玩味生活等公開報導
